# 칼로리 계산 및 영양정보

## 출처 우선순위

1. 사용자가 직접 선택한 식품영양성분 데이터베이스의 100g 기준값.
2. 사용자가 직접 입력한 100g당 열량.
3. 검증된 표준값이 없을 경우에만 AI 추정값(미확정 표시).

계산식: 음식 kcal = 섭취량(g) × 해당 음식 kcal/100g ÷ 100.
식사 합계는 확정 음식별 열량을 합산한다.
단위가 100ml인 원본값을 임의로 100g 기준값으로 변환하지 않는다.

## 검색

음식명을 특수문자 및 공백 제거해 정규화한다. 완성형 한글을 초성·중성·종성
자모로 분해한 뒤 2문자 단위 공통 쌍과 편집거리를 결합해 후보를 순위화한다.
매칭은 자동 확정이 아니며 사람의 확인을 거쳐 출처 코드가 기록된다.

## 데이터 수급

공식 출처: https://various.foodsafetykorea.go.kr/nutrient/general/down/historyList.do
공공데이터포털: https://www.data.go.kr/data/15100070/standard.do

2026-08-28 공식 음식 DB 엑셀 19,617건을 확보해 `data_source/`에 보존했다.
그중 100g 기준 13,877건을 `assets/nutrition/seed.json`에 담았다.
100ml 기준 5,740건은 밀도 가정을 통한 오차를 피하려고 검색 데이터에 포함하지 않았다.
누락된 탄수화물·지방 값은 0으로 추정하지 않고 null로 유지한다.

tools/import_nutrition.py는 공식 CSV/XLSX를 입력받아 숫자·단위·식품코드를
검사하고 100g 데이터를 생성한다. 원본의 출처명을 함께 유지한다.
