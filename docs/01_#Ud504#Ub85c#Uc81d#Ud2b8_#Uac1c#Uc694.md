# 프로젝트 개요 (v0.2)

## 목적
한식 한상차림 사진 속 각 음식의 이름·위치·추정 중량을 구조화하고, 사용자 검수 후 식사 열량을 기록한다.

## 처리 경계
- 입력: 사용자가 촬영/선택한 이미지와 클라우드 전송 동의.
- 추론: Ollama Cloud가 음식별 JSON을 반환한다. 정확도는 보장하지 않는다.
- 계산: 100g당 검증된 값이 있을 때 `섭취량/100 * 열량`을 적용한다. 없으면 AI 추정값임을 명시한다.
- 확정: 사용자 검수를 거쳐 로컬 SQLite로 저장한다.

## 수용 조건과 현재 갭
| 조건 | 현재 상태 |
|---|---|
| 음식별 인식 및 좌표 검사 | 구현, 실제 모델 테스트 미실시 |
| 이미지 위 선택 가능한 오버레이 | 구현, 실기기 검증 미실시 |
| 공공 영양 DB | 미완료: 라이선스 확인 및 원본 데이터 적재 필요 |
| 정규화 로컬 기록 | 신규 v2 스키마 구현, 마이그레이션 필요 |
| Android/iOS 빌드 | 미검증: SDK 및 플랫폼 프로젝트 미포함 |

v0.2는 보완 소스이며 완료 판정은 빌드, 실제 데이터 검증, 사용자 시나리오 테스트 후에만 가능하다.
