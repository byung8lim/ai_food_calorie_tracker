# 테스트 계획과 확인 결과

## 제공된 단위 테스트
- 열량 계산: 210 × 150 / 100 = 315.
- 중복 음식 ID 거부.
- 화면 경계 밖 bbox 거부.
- 추가 예정: 정규화 DB 원자성, SQL 외래키, 통계 합계, 선택 박스 터치, 사용자 입력 오류, API 타임아웃.

## 수동 시험 시나리오
1. 사진 촬영과 갤러리 선택 각각 1회.
2. 5접시 한식 사진을 분석, 음식별 목록과 박스 매핑 확인.
3. 유효 박스 및 결측 박스 확인, 사진 재촬영 후 이전 결과 초기화 확인.
4. 중량 편집 시 합계 재계산 확인.
5. 인터넷 차단 뒤 식사 목록과 통계 조회 확인.
6. 기기 재실행 후 데이터 지속성 확인.
7. API 인증 오류와 응답 스키마 오류 시 안내 확인.

## 검증 상태
이 작업 환경에는 Flutter 및 Dart 실행기가 없으므로 `flutter analyze`, `flutter test`, Android/iOS 빌드를 실행하지 못했다. 구현 코드가 컴파일된다고 판정할 수 없다.
