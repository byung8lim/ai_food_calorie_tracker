# v0.4 변경 및 검증 기록 (2026-10-25)

## 실제 데이터

- K-FIND 출처: https://various.foodsafetykorea.go.kr/nutrient/general/down/historyList.do
- 표준데이터: https://www.data.go.kr/data/15100064/standard.do
- 공식 2026-08-28 음식 DB 19,617건 원본을 data_source/에 보존하였다.
- assets/nutrition/seed.json은 원본의 100g 기준 13,877행을 포함한다.
- 100ml을 100g으로 임의 환산하지 않았다.
- 원본의 100ml 기준 5,740건은 별도 밀도 가정 없이 원본 엑셀에 보존하였다.
- 누락 영양소 값은 0으로 임의 추정하지 않고 null로 보존하였다.

## 개선

1. 종횡비를 보존한 사진 표시 영역과 박스 좌표 일치.
2. 다중 사진 분석 결과 집계, 사용자가 중복 항목 병합·분리.
3. 음식명 정규화 및 편집거리 검색, 공공 데이터 식품 코드 보존.
4. SQLite user_version 마이그레이션 및 식품 코드 컬럼.
5. GoRouter 화면 분리, 영양 매칭 선택 UI, 단위 테스트 코드.

## 미완료·검증 불가

- Android SDK 및 Xcode 미설치: Android/iOS 빌드와 실기기 검증 미실행.
- 식약처 DB 자동 갱신 및 재배포 조건 검토 미완료.
- 자동 교집합/합집합 및 영역 분할 추론, 이미지 영구 저장 미구현.
- 개인정보 삭제·동의 및 분석 중 네트워크 취소 미구현.
- 기존 v0.1 DB에서 v0.2 파일로 데이터 이관 미구현.
- 서버 키 프록시, 실기기 카메라 권한·API 통합 검증 미완료.

이 소스는 개선 중인 v0.4이며 실기기 배포 검증이 끝난 상용 완성판으로 판정하지 않는다.
